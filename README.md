# Snake---Metal-Gear
Jogo desenvolvido no 8°Semestre da Engenharia da Computação

INTRODUÇÃO PARA SUA EXECUÇÃO:

Instalar a biblioteca pygame em seu pc.
(A instalção pode ser realizada pelo próprio VS CODE)

Extraia o arquivo rar em seu computador.
Abra o código e em seu terminal digite "py Snake.py"

Teclas para jogar: CIMA, BAIXO, ESQUERDA E DIREITA

Aprtoveite o jogo!!!
Obrigado.
