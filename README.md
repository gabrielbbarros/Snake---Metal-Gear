# Snake---Metal-Gear
Jogo desenvolvido no 8°Semestre da Engenharia da Computação

INTRODUÇÃO PARA SUA EXECUÇÃO:

Instalar a biblioteca pygame em seu pc.
(A instalção pode ser realizada pelo próprio VS CODE)

Crie uma pasta e salve o código, junto com a imagem e o arquivo mp3

Abra o código em seu VS CODE e logo em seguida o terminal.
Digite no terminal ("py [arquivo do codigo]") e de o ENTER

Abrira uma tela, na onde voce consegue controlar o snake, pelas teclas de CIMA,BAIXO,ESQUERDA E DIREITA do telcado.

Aprtoveite o jogo!!!
Obrigado.
